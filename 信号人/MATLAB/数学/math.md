# <center>解方程


### 多元变量
```
%定义变量
syms x y 

%表达式a,b,c
f = [x + 2 * y == 1, 2 * x + y == 5];

%赋值按照[x ,y]顺序放在a,b中；可不写后面[],赋值按照变量出现顺序
[a, b] = solve(f, [x, y])
```
